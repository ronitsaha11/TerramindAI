# Datasets

## `bangalore_osm.geojson`

Sample data for the spatial and natural-language queries: parks, hospitals
and railway stations in central Bengaluru.

| | |
| --- | --- |
| Source | [OpenStreetMap](https://www.openstreetmap.org), via the Overpass API |
| Extracted | 28 August 2026 (the commit that added it, `9e02be3`) |
| Extent | Clipped to longitude 77.4 to 77.6, latitude 12.8 to 13.0 |
| Features | 1,188: 672 parks, 473 hospitals, 43 stations; 755 polygons, 432 points, 1 line |
| Fields kept | `name`, `category`, `osm_id`, `osm_type`; all other OSM tags were dropped |
| Size | About 380 KB |

### Changes from the source data

- Clipped to the extent above.
- Invalid OSM polygons repaired with a zero-width buffer (`buffer(0)`), so
  `ST_Intersects` cannot fail on malformed geometry.
- Each feature reduced to the four fields above. `category` (`park`,
  `hospital`, `station`) is TerraMind's own label, not an OSM tag.

The exact Overpass query and conversion script were not committed, so the
extract cannot be regenerated byte for byte. `osm_id` and `osm_type` link each
feature back to its OpenStreetMap object.
